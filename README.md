# เลขงวดหน้า (Thai Lottery Number Generator)

เว็บแอปหน้าเดียวที่สร้างชุดเลขสลากกินแบ่งรัฐบาลสำหรับงวดถัดไป โดยรวมคะแนนจาก 3 แหล่ง
สถิติผลรางวัล 24 งวดล่าสุด · โหราศาสตร์ไทยของวันออกรางวัล · วันเกิดของผู้ใช้ (ถ้ากรอก)

**ใช้งาน:** https://idblackdesert-max.github.io/thai-lotto-calc/ (เปิดบนมือถือแล้วกด "เพิ่มลงหน้าจอหลัก" เพื่อติดตั้งเป็นแอป)

> ⚠️ ผลลัพธ์นี้จัดทำเพื่อความบันเทิง ผลสลากเป็นการสุ่ม ไม่มีวิธีใดเพิ่มโอกาสถูกรางวัล

| ประเภท | จำนวนชุด | หลัก |
|---|---|---|
| รางวัลที่ 1 | 1 | 6 |
| เลขหน้า 3 ตัว | 2 | 3 |
| เลขท้าย 3 ตัว | 2 | 3 |
| เลขท้าย 2 ตัว | 1 | 2 |

## หลักการ

- **ไม่มี server** — เว็บเป็นไฟล์ static บน GitHub Pages คำนวณทุกอย่างในเบราว์เซอร์ **วันเกิดไม่ออกจากเครื่องผู้ใช้**
- **GitHub Actions ดึงข้อมูลแทน server** ทุกวัน 17:30 น. (เวลาไทย) ถ้ามีงวดใหม่จะ commit `public/data/draws.json` แล้ว build + deploy ใหม่
- **อินพุตเดิม = เลขเดิมเสมอ** (งวด + วันเกิด + น้ำหนัก) ใช้ตัวสุ่มแบบ seed (mulberry32) ปุ่ม "สุ่มชุดใหม่" เพิ่มค่า nonce เพื่อดูชุดอื่น
- **อธิบายได้ทุกหลัก** — แตะตัวเลขเพื่อดูว่าคะแนนมาจากแหล่งไหนเท่าไร

### การคำนวณ (สรุป)
1. **สถิติ** — ความถี่ของเลข 0–9 ในแต่ละตำแหน่ง ถ่วงน้ำหนักงวดใหม่มากกว่า (decay 0.95) + Laplace smoothing
2. **เลขประจำวัน** ของวันออกรางวัล (อาทิตย์ 1 … เสาร์ 7, ออกรางวัลตอนบ่าย วันพุธจึงใช้ 4)
3. **เลขศาสตร์วันที่** — ผลรวม วัน+เดือน+ปี พ.ศ. ลดเหลือหลักเดียว (รองลงมา: วัน, เดือน)
4. **ข้างขึ้นข้างแรม** (โดยประมาณ จากมุมดวงจันทร์ — ปฏิทินจันทรคติไทยมีอธิกมาส)
5. **ปีนักษัตร** ชวด=1 … กุน=12
6. **วันเกิด** — เลขวันเกิด, เลขศาสตร์วันเกิด, ทักษา (เพิ่ม ศรี/เดช, ลดเลขกาลกิณีถ้าติ๊ก "ตัดเลขกาลกิณี")

คะแนนรวม = Σ (น้ำหนัก% × คะแนนแหล่งนั้น 0..1) · ชุดที่ 1 = คะแนนสูงสุดทุกหลัก · ชุดที่ 2 = สุ่มถ่วงน้ำหนัก ไม่ซ้ำชุดที่ 1

## แหล่งข้อมูล

| แหล่ง | ใช้ทำอะไร |
|---|---|
| **สำนักงานสลากกินแบ่งรัฐบาล** `www.glo.or.th/api` | แหล่งหลัก — `lottery/getPeriodsByYear` (วันออกรางวัลทั้งปี) + `checking/getLotteryResult` (ผลรายงวด) |
| Sanook (news.sanook.com/lotto) | ตรวจทานด้วยมือ |
| ~~Thai Lotto API (rayriffy)~~ | เดิมเป็นแหล่งหลักในแผน แต่ repo ถูก archive และโดเมนปิดแล้ว (ตรวจ พ.ย. 2569) |

ถ้าแหล่งข้อมูลใช้ไม่ได้ สคริปต์จะ **คงไฟล์เดิมไว้** ขึ้นคำเตือนใน Actions และยัง deploy ต่อได้
ต้องการเปลี่ยนแหล่ง: เขียนไฟล์ใหม่ใน `scripts/sources/` ตาม interface `DrawSource` (`scripts/sources/types.ts`) แล้วเปลี่ยนใน `scripts/fetch-draws.ts`

## ตั้งค่า repo ครั้งแรก (ทำครั้งเดียว)

1. repo ต้องเป็น **Public** (GitHub Pages ฟรีต้อง Public)
2. **Settings → Pages → Source** เลือก **GitHub Actions**
3. **Settings → Actions → General → Workflow permissions** เลือก **Read and write permissions**
4. แท็บ **Actions** → "Update data & deploy" → **Run workflow** เพื่อ deploy ครั้งแรก
5. (ทางเลือก) โดเมนของตัวเอง: เพิ่มไฟล์ `public/CNAME` และตั้ง `BASE_PATH: /` ใน `.github/workflows/deploy.yml`

ไม่ต้องมี secret ใด ๆ และไม่มีข้อมูลส่วนตัวใน repo

## รันในเครื่อง (สำหรับพัฒนา)

ต้องมี Node.js 22 ขึ้นไป (แนะนำ 24 ตาม `.nvmrc`)

```bash
npm install
npm run fetch-data   # ดึงผลล่าสุดลง public/data/draws.json
npm run dev          # เปิด http://localhost:3000
npm test             # เทสทั้งหมด
npm run lint && npm run typecheck
```

## แก้ค่าโดยไม่ต้องแตะโค้ด (`config/`)

| ไฟล์ | เนื้อหา |
|---|---|
| `draw-exceptions.json` | วันออกรางวัล: ปกติ 1/16 · กฎรายเดือน (ม.ค. 2/17, พ.ค. 2/16) · override รายปี — **ตรวจกับปฏิทินสำนักงานสลากฯ ทุกต้นปี** |
| `astrology.json` | เลข/สีประจำวัน, ลำดับทักษา, ปีนักษัตร (เริ่มปี 1 ม.ค. หรือสงกรานต์), ความแรงของเลขหลัก/รอง |
| `defaults.json` | น้ำหนักเริ่มต้น, decay, ค่าหักเลขกาลกิณี, จำนวนงวดที่ใช้/เก็บ, เวลาตัดรอบ 16:00, เตือนข้อมูลเก่า 20 วัน |

ทุกไฟล์ถูกตรวจด้วย zod ตอน build/test ถ้าใส่ค่าผิดรูปแบบ build จะไม่ผ่าน
